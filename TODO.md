Assignment Instructions
Project 09: Build a Responsive Clone of Netflix's Homepage Using Tailwind CSS
Objective:
Develop practical experience in building modern, responsive user interfaces using Tailwind CSS.

Understand how to replicate a globally recognized UI by analyzing layout, spacing, and visual hierarchy.

Learn to design a pixel-accurate homepage clone with a strong focus on responsiveness and usability.

Task:
Your task is to create a responsive clone of Netflix’s homepage using Tailwind CSS. The clone should replicate the iconic look and feel of Netflix’s homepage while ensuring seamless responsiveness across various devices.

Reference Website:

🔗 https://www.netflix.com/in/

Requirements:
Tailwind CSS:
Use Tailwind CSS to style all elements and components of the homepage clone.

Leverage Tailwind utility classes for layout, spacing, typography, and responsiveness.

Avoid custom CSS as much as possible to demonstrate Tailwind proficiency.

Design Replication:
Replicate key design elements such as:

Navigation bar

Hero section with background image

Content rows / movie sections

Footer layout

Ensure the clone closely matches the visual layout and styling of Netflix’s homepage.

Instructions:

1. Homepage Analysis:
   Analyze Netflix’s homepage structure, including spacing, typography, colors, and content alignment.

Observe responsive behavior on desktop, tablet, and mobile devices.

2. Development Tasks:
   Build the homepage using HTML + Tailwind CSS, including:

Responsive navigation bar

Hero banner with CTA buttons

Multiple content rows (movies/shows)

Footer section

Apply responsive utility classes to ensure proper layout across all screen sizes.

Test the homepage on different devices and browsers for consistency.

Deliverables:
Submit a GitHub repository or zipped folder containing:

index.html

Tailwind CSS linked via CDN or build setup

Images and assets used in the project

A brief README file or PDF including:

Project overview

Tailwind utility classes and components used

Screenshots of desktop, tablet, and mobile views

Evaluation Criteria:
Accuracy of Netflix homepage design replication

Effective use of Tailwind CSS utility classes

Responsiveness across multiple devices

Clean and maintainable code structure

Bonus: Smooth hover effects and subtle animations
